- 设置的「来源」里多了「Yumina 账号」，排在第一个。浏览器里登录一次就能聊，每月送免费蘑菇币，不用自己找 Key。
- 第一次打开的欢迎页、教你拿 Key 的那页，第一个选项都是「用 Yumina 账号」。
- 用自己 Key 但还没填的时候，设置里有一行「没有 API Key？点这里用 Yumina 账号免费玩」。
- 先古之民 25 秒还没回话，会多出一个「（还没回话……不等了）」。点了这句不算，可以再点「交谈」重来。
- Yumina 账号下选的模型连续出错时，接下来十分钟改用账号的默认模型，屏幕上会提示一次。
- 设置页顶上会显示新版本，点「一键更新」下载，退出游戏后自动装上。
- 设置页左下角多了「反馈」：写下来直接发给我们，可以勾选附上最近一次对话。
- 压缩包里多了「点我安装.bat」，会自己找到游戏目录，把模组和 BaseLib 放进去。
