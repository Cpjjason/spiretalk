讓八位先民和商人可以對話。先民事件裡多一個「交談」選項，商店右上角多一個「聊聊」按鈕。

[img]https://raw.githubusercontent.com/Cpjjason/spiretalk/main/workshop/art/b1_zht.jpg[/img]
每次見面能說三句，說的話會改變好感（敵意 / 陌生 / 友好 / 親近 / 摯愛）。

第一次聊過之後，對方會送你信物。信物是一件遺物，好感升檔時當場升級，到摯愛時變成誓約。設定裡有信物圖鑑。

先民有時會提一個約定，比如活著走到第二章、這一章不喝藥水。答應後會變成遺物欄裡的一件遺物，守住了給好感和 50 金幣。聊天中得到的獎勵和約定，「儲存並離開」後依然保留。

角色記得之前幾局聊過的內容，可以在設定的「角色記憶」裡檢視和修改。

每局最多遇到兩次新事件：翻倒的貨車、路邊歇腳的先民。

好感高的先民可能把自己的遺物放到商店裡賣。

一局結束時，好感最高的那位會在結算頁說幾句。

[img]https://raw.githubusercontent.com/Cpjjason/spiretalk/main/workshop/art/b2_zht.jpg[/img]
最省事：用 Yumina 帳號登入。第一次開啟會問角色怎麼說話，選「用 Yumina 帳號」，在瀏覽器裡登入一次、點「允許」就行。每個帳號每月有免費額度，不用自己找 API 金鑰。

也可以填自己的金鑰：OpenRouter、OpenAI、Anthropic、Gemini、DeepSeek、智譜、矽基流動、阿里雲百煉、本機 Ollama 等。AI 臺詞會結合這一局的血量、牌組、遺物，你也可以自己打字說。

完全不用 AI 也可以：角色說預先寫好的臺詞，你從三個回覆裡選，其他功能不變。隨時可以在設定頁頂部的「模式」裡切換。

先民超過 25 秒還沒回答時，可以選擇不等了，這一句不算用掉。

需要 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127]BaseLib[/url]。
支援連線：每個人和自己的先民、商人聊，隊友在旁邊看著。隊友說的話顯示在你螢幕左邊；角色知道你和誰一起來，會拿你們比較，能被你說動去喜歡或討厭某個隊友，也可以把獎勵給你的朋友。房間裡所有人要裝同一個版本的 SpireTalk。
跟隨遊戲語言，遊戲支援的 16 種語言全部涵蓋：選單、遺物、事件、寫好的臺詞和角色說的話。
相容 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3750930021]Ancient Affection[/url]（先古好感度），裝了會直接用它的好感度。
預設原版畫風。裝了 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3748235030]AncientWaifus[/url]（美術 LunchShark，動畫 Dodobird）和 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3748331824]Merchant2CuteII[/url]（作者 LinXce）後，路邊事件插圖和信物圖示會換成照它們的角色形象畫的版本，角色形象歸原作者。路邊事件插圖和信物圖示是生成的美術。
設定頁有「回饋」，可以直接寫給我們；討論區也可以。
