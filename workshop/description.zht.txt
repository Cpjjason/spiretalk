[b]先民會回話了。[/b]八位遠古先民和商人都會用自己的口吻跟你說話，記得你上一局說過什麼，會向你提要求，還會把一件隨關係成長的遺物交給你。用你自己的 API Key，在遊戲裡直接執行，不用註冊賬號，也不連任何伺服器。

[b]兩種畫風都支援：[/b]預設是原版畫風；裝了 [b]AncientWaifus[/b] + [b]Merchant2CuteII[/b]，模組自己的插畫會自動換成娘化畫風。

[h1]有什麼[/h1]

[h3]交談[/h3]
每位先民的頁面多一個「交談」，商店裡多一個「聊聊」按鈕。每次拜訪能說三句：點選建議的回覆，或者自己打字。涅奧、歐洛巴斯、諾奴佩普、佩爾、達弗、坦克斯、特茲卡塔拉、瓦庫和商人，各有各的性格、價值觀和記憶。

[h3]他們記得你[/h3]
你跟涅奧說過的話，下一局涅奧還記得（按存檔分開，可以關掉）。以前的見面會壓成幾條簡短的筆記；設定裡的「角色記憶」頁面可以檢視、修改、新增或刪除每個人記得的事。你說的每句話都會影響好感，按那位角色自己的價值觀來判斷：敵意 / 陌生 / 友好 / 親近 / 摯愛。

[h3]約定[/h3]
見面時先民可能會向你提要求：[i]活著走到下一章[/i]、[i]到那之前不喝藥水[/i]、[i]在我店裡花夠 150 金幣[/i]……用按鈕回答就行。條件由模組給出，遊戲可以準確判定。守住了：好感和金幣；沒守住：只會聽到一句失望的話，沒有別的懲罰。進行中的約定顯示在遺物欄下面。

[h3]信物[/h3]
關係夠好時，先民會把自己的信物交給你：一件分 I / II / III 級的遺物，等級跟著關係走，好感一過線，這局當場就會升級。每守住一次約定，信物上就多一道刻痕。九件信物，一人一件，各有各的性格：涅奧的會在戰鬥後給你回血，每局還能在你瀕死時留你 1 點生命；坦克斯的讓你的第一次攻擊更狠；瓦庫的用鮮血換力量；商人的是一本記著折扣的賬本。

[h3]先民遺物上架[/h3]
喜歡你的先民，可能會把 [i]自己殿裡[/i] 的一件遺物託給商人留給你。這些遺物平時只能在他們那裡拿到，上架後按稀有遺物定價。

[h3]回顧[/h3]
一局結束時，最瞭解你的那位會在結算頁說幾句：你們的約定、你倒在了哪裡、你是怎麼贏的。

[h3]路上偶遇[/h3]
每局最多兩次新事件，各配一張插畫。[b]翻倒的貨車[/b]：商人的貨車翻了，你可以幫忙（換一瓶藥水和下次折扣）、順走一件遺物（這局每家商店都會漲價），或者直接走開。[b]路邊的先民[/b]：一位你聊過的先民疲憊地坐在路邊，給他要的東西或者坐下陪一會兒，會升級你的一張牌。他們會用自己的口吻說話，下次見面還記得。

[h3]獎勵真實，規則透明[/h3]
換一套遺物、金幣、回血、藥水、商店折扣。每一項獎勵都由模組按固定規則校驗，再透過遊戲自己的指令發放。AI 只負責說話，從不直接改動你的這一局。
